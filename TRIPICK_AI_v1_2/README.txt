TRIPICK AI v1

1. 이 폴더를 Windows 노트북에 저장합니다.
2. Python이 설치되어 있어야 합니다.
3. FFmpeg가 설치되어 있어야 합니다.
4. START_TRIPICK.bat를 더블클릭합니다.
5. 브라우저에서 숙소 사진을 올리고 15/20/30초를 선택한 뒤 '여행쇼츠 만들기'를 누릅니다.

현재 v1 기능
- 사진 최대 14장
- 15/20/30초 선택
- 9:16 1080x1920 MP4
- 부드러운 줌 효과
- 저비용 로컬 제작 (AI 영상 생성 크레딧 불필요)
